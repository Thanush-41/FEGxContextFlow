# Compliance note

This prototype uses fictional matches, synthetic profiles, demo credits, and sample receipts. It performs no real-money placement or payment processing and makes no claim of production regulatory compliance.

Optional notifications default off and require consent plus an eligible synthetic profile. The demo applies device-local quiet hours, a daily cap, and a minimum interval. Underage, unverified, at-risk, and excluded synthetic states are suppressed. Voice, touch, and handoff actions share the same eligibility checks. Research is treated as evidence, not authorization; the user chooses the outcome and stake, receives an exact readback, and must explicitly confirm. Any relevant change invalidates the review.

Secrets are supplied through ignored environment files. Reviewers must use only fictional data. Production use would require operator identity and exclusion integration, legal and security review, accessibility validation, authorized sports data, operational monitoring, and incident processes.

The detailed requirement-to-control mapping is in [`submission/review/ContextFlow_Compliance_Note.pdf`](../submission/review/ContextFlow_Compliance_Note.pdf).
