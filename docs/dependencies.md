# Dependencies and AI-use disclosure

Exact JavaScript versions are pinned in the lockfiles under `mobile/`, `server/`, and `shared/`. Material direct components include React, React Native, React Native WebRTC, React Native SVG, Async Storage, NestJS, Express integration, SQLite through Node, Zod, RxJS, WebSocket support, TypeScript, Jest, and platform build tooling. Their upstream licences and notices remain authoritative and must be rechecked before redistribution.

The hosted demo uses Supabase Edge Functions/Postgres and Azure OpenAI realtime voice. Native builds also depend on Apple and Android SDKs and their applicable platform terms. Production sports feeds, identity, payments, settlement, APNs/FCM delivery, and operator systems are not bundled integrations.

Mobbin was used only for visual-pattern research; links and the original-design statement are recorded in the README. Submission assets identify fictional/sample content and label unbuilt Watch and Mac surfaces as concepts. Any externally sourced or generated media must retain its source and permission record before final submission.
