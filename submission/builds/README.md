# ContextFlow native demo builds

These are internal hackathon builds using sample data and demo credits.

- Android APK: Release build, installed and inspected on an emulator. Uses development signing; this is not a store release.
- iPhone app archive: signed development app from the successful physical-device QA build. It requires a compatible registered device and signing setup; it is not an App Store IPA.

Select the eligible-adult synthetic fixture in Menu → Settings before the demonstration. Optional notifications start off. Real identity services and production sports feeds are outside this build.

The physical-iPhone typed QA journey passed. Three consecutive human-spoken runs, complete surface lifecycle/accessibility inspection and final media playback remain required. See the review evidence checklist. Build hashes are recorded in build-manifest.json.
